# 自动微分与自定义函数

`ft.grad(outputs, inputs, *, seed=None)` 从已有表达式生成导数图，返回待计算 Tensor。读取梯度结果或调用 `ft.evaluate` 时再编译执行。可微类型为 `ft.fp32`、`ft.fp16`、`ft.bf16`。

<a id="grad"></a>
## 求导参数与返回值

| 参数 | 含义 |
| --- | --- |
| `outputs` | 一个浮点 Tensor，或非空的浮点 Tensor tuple/list。 |
| `inputs` | 一个待求导的浮点 Tensor，或非空的浮点 Tensor tuple/list。输入可以是表达式中的中间张量。 |
| `seed` | 输出的余切种子。0-D 标量输出可省略，默认种子为 1；非标量输出须显式传入。单输出使用 Tensor 种子，多输出使用相同长度的 tuple/list；序列容器类型可互换，每项的 Engine、shape 和 dtype 均须与对应输出一致。 |

`inputs` 为单 Tensor 时返回一个 Tensor，为 tuple/list 时返回按输入顺序排列的 tuple。多个输出的余切贡献相加；未连接到输出的输入得到同形状、同类型的零梯度。每次调用生成独立结果，可以重复求导或继续对导数求导。

`ft.grad` 接收运行时 Tensor，在普通 Python 代码中调用；`ft.fun` 的隔离追踪内使用原语组合或纯 VJP 规则表达导数。

```python
import fugatensor as ft

x = ft.tensor([2.0, 3.0])
y = ft.square(x)
dx = ft.grad(y, x, seed=ft.ones_like(y))
print(dx.tolist())  # [4.0, 6.0]
```

多个输出和输入可以一起求导：

```python
import fugatensor as ft

x = ft.tensor(2.0)
z = ft.tensor(3.0)
y = x * z
dx, dz = ft.grad((y, x * x), (x, z),
                 seed=(ft.tensor(1.0), ft.tensor(1.0)))
print(dx.tolist(), dz.tolist())  # 7.0 2.0
```

<a id="higher-order"></a>
## 高阶求导与求值

```python
import fugatensor as ft

x = ft.tensor(2.0)
y = x * x * x
first = ft.grad(y, x)
print(first.tolist())   # 12.0
second = ft.grad(first, x)
print(second.tolist())  # 12.0
```

求值后保留表达式来源，因此 `first.tolist()` 后仍能构造二阶导数。高阶求导要求导数图中的活跃路径具备相应规则；缺少规则的外部 kernel 路径会在构造导数图时被拒绝。`reshape` 的 VJP 将余切恢复为输入形状，具体规则见[高阶导数](../architecture/自动微分与自定义算子.md#higher-order)。

<a id="stop-gradient"></a>
## 显式停止梯度

`x.detach()` 和 `ft.stop_gradient(x)` 返回保留数值依赖、断开求导路径的 Tensor。待计算输入仍在求值时执行，断点之前的输入不接收这条路径的余切。

两个入口均接受 Tensor 和隔离追踪中的 TraceTensor，可用于 `ft.fun.forward` 与 `ft.fun.vjp`。追踪时生成 `fuga.stop_gradient`：前向保留原值，JVP 切线和 VJP 余切在此停止传播。数值降级时直接使用输入值。`ft.grad` 本身仍在隔离追踪之外调用。

```python
import fugatensor as ft

x = ft.tensor(3.0)
y = ft.stop_gradient(x * x) + x
print(y.tolist())            # 12.0
print(ft.grad(y, x).tolist()) # 1.0
```

普通 `ft.fun` 的自动求导也遵守该边界：

```python
import fugatensor as ft

class Residual(ft.fun):
    def forward(self, x):
        return ft.stop_gradient(x * x) + x

x = ft.tensor(3.0)
y = Residual()(x)
print(y.tolist())            # 12.0
print(ft.grad(y, x).tolist()) # 1.0
```

显式 VJP 可以冻结导数表达式中的系数；以下规则使一阶导数为 `x`，继续求导得到零：

```python
import fugatensor as ft

class FrozenSlope(ft.fun):
    def forward(self, x):
        return 0.5 * x * x

    def vjp(self, primals, outputs, cotangents):
        return (ft.stop_gradient(primals[0]) * cotangents[0],)

x = ft.tensor(3.0)
first = ft.grad(FrozenSlope()(x), x)
print(first.tolist())           # 3.0
print(ft.grad(first, x).tolist()) # 0.0
```

被停止梯度隔离的外部 kernel 只保留数值依赖，该路径无需提供微分规则；其他活跃路径仍按规则校验。

<a id="custom-functions"></a>
## 自定义函数 `ft.fun`

继承 `ft.fun`，定义 `forward(self, ...)`，通过实例调用构图。至少传入一个 Tensor；前向返回一个 Tensor 或非空 Tensor tuple。普通前向可由 Fuga IR 自动求导；需要指定梯度公式或接入外部 kernel 时，提供纯函数规则 `vjp(self, primals, outputs, cotangents)`。

| 接口 | 用法 |
| --- | --- |
| `forward(self, ...)` | 按普通参数构造并返回前向表达式。 |
| `vjp(self, primals, outputs, cotangents)` | 三个参数均为 tuple：全部 Tensor 输入的原值（含整数与布尔）、全部前向公开输出、按公开输出顺序排列的余切。未使用的浮点输出对应零 Tensor，整数或布尔输出对应 `None`。返回所有浮点 Tensor 输入的梯度 tuple，按输入顺序排列，shape 和 dtype 须逐项匹配。整数、布尔和静态参数不占返回梯度的位置。 |
| `op.clear_cache()` | 使已记录的调用失效；修改未自动跟踪的闭包或全局捕获后，重新构图。 |

单输入的 VJP 也返回 tuple，例如 `(dx,)`。规则直接使用输入、输出和余切构造表达式，每个浮点 Tensor 输入均须返回梯度。静态非 Tensor 参数在追踪前向时保持原值，不进入 `primals`。普通前向支持自动 VJP/JVP；提供显式 VJP 的函数当前不接受活跃 JVP 变换。

```python
import fugatensor as ft

class Square(ft.fun):
    def forward(self, x):
        return ft.square(x)

    def vjp(self, primals, outputs, cotangents):
        (x,) = primals
        (dy,) = cotangents
        return (2.0 * x * dy,)

x = ft.tensor(3.0)
y = Square()(x)
print(ft.grad(y, x).tolist())  # 6.0
```

`forward` 和 `vjp` 都会隔离追踪，方法内的 Python 分支须由静态元信息决定。递归、读取真实张量数据及追踪期间修改函数状态会报错。实例或类的配置属性接受不可变 `bool` / `int` / `float` / `str` / `None`、类型对象（如 `ft.fp16`）及其嵌套 tuple；Tensor 状态通过参数传入。修改已记录调用的方法或配置后，应重新调用构图；旧调用会被拒绝。定义检查见[自定义函数边界](../architecture/自动微分与自定义算子.md#custom-fun)。
