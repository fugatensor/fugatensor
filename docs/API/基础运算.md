# 基础运算

<a id="operations"></a>

## 逐元素计算

运算返回待计算的 Tensor，读取结果或调用 `ft.evaluate` 时执行。

```python
import fugatensor as ft

x = ft.tensor([1, 2, 3])
y = ft.where(x > 1, ft.sqrt(x), x / 2)
print(y.tolist())
```

| 用法 | 函数入口 |
| --- | --- |
| `x + y`、`x - y`、`x * y`、`x / y` | `add`、`subtract`、`multiply`、`divide` |
| `-x`、`x.square()` | `negative`、`square` |
| `ft.exp(x)`、`ft.log(x)`、`ft.sqrt(x)` | 指数、自然对数、平方根 |
| `x == y`、`x != y`、`x < y`、`x <= y`、`x > y`、`x >= y` | `compare(x, y, predicate)`；返回 bool Tensor |
| `ft.where(condition, x, y)` | 按 bool Tensor 逐元素选择；至少一个值为 Tensor |
| `x.astype(ft.fp16)` | `cast(x, dtype)` |
| `ft.zeros_like(x)`、`ft.ones_like(x)` | 同 shape、dtype 和设备的常量 |

两个 Tensor 逐元素运算须有相同 shape、dtype 和设备。Python 数值可放在任一侧，按 Tensor 的类型和形状构造常量。`compare` 的 predicate 为 `eq/ne/lt/le/gt/ge`。`where` 的条件形状与两个值一致，梯度沿选中的值传播。

<a id="shape-maps"></a>

## 改变形状和维度

`reshape(x, shape)` 保持元素次序；`transpose(x, permutation=None)` 按轴排列元素，默认反转轴顺序，也可写 `x.T`。`broadcast_to(x, shape)` 从右侧对齐维度，映射的输入维度须等于输出维度或为 1。

```python
x = ft.tensor([[1, 2, 3]])
y = ft.broadcast_to(x, (2, 3))
print(y.T.tolist())  # [[1.0, 1.0], [2.0, 2.0], [3.0, 3.0]]
```

需要明确放置输入轴时使用 `broadcast_in_dim(x, shape, dimensions)`。`dimensions` 按递增顺序列出每个输入轴对应的输出轴，例如 `broadcast_in_dim(x, (2, 1, 3), (1, 2))`。这些变换与相邻逐元素计算保留融合机会。

<a id="reductions"></a>

## 归约

`sum(x, axis=None, *, keepdims=False, dtype=None)`、`amax(x, axis=None, *, keepdims=False)`、`mean(x, axis=None, *, keepdims=False, dtype=None)` 支持单轴或轴 tuple；负轴从末尾计数，`axis=None` 归约全部轴。

```python
x = ft.tensor([[1, 2, 3], [4, 5, 6]])
print(x.sum(axis=1).tolist())              # [6.0, 15.0]
print(x.mean(axis=0, keepdims=True).tolist())  # [[2.5, 3.5, 4.5]]
```

全归约返回 0-D Tensor。`keepdims=True` 将被归约维度保留为 1。`sum` 按输入 dtype 逐次累加；需要更高精度时用 `sum(dtype=ft.fp32)`。空归约域的和为 0。`amax` 要求归约域非空，传播 NaN，梯度在相同最大值之间平均分配；NaN 最大值对应 NaN 梯度。`mean` 由和与除法组成，要求浮点计算类型。

<a id="matmul"></a>

## 矩阵乘法

```python
a = ft.tensor([[1, 2], [3, 4]])
b = ft.tensor([[2, 0], [0, 2]])
print((a @ b).tolist())  # [[2.0, 4.0], [6.0, 8.0]]
```

`matmul(a, b, *, transpose_a=False, transpose_b=False)` 与 `a @ b` 使用末两维作矩阵维度，前面的批维度须完全相同。转置标志直接改变乘法的索引方式。CPU 输入为 `fp32` 或 `fp16`，CUDA 另支持 `bf16`；两个输入 dtype 相同，用 fp32 累加，输出保留输入 dtype。

CUDA 矩阵乘法由 NVIDIA cuBLASLt 执行，fp32 输入允许 TF32 乘法，存储与累加保持 fp32；描述符、算法和工作区在准备计划时确定。CPU fp32 使用单线程 OpenBLAS SGEMM，fp16 使用 ASK 自有实现，沿 K 逐步乘加。库调用的累加顺序由库决定。相邻逐元素表达式在各自区域内融合。JVP、VJP 和高阶导数继续使用同一套原语。

<a id="types-and-limits"></a>

## 类型与数值

加、减、乘、归约支持五种数值类型。除法、指数、对数和平方根支持浮点类型。bool 支持比较、选择、形状变换、cast 和常量构造。精度转换须显式使用 `astype`，广播须显式使用广播接口。

`int32/int64` 加乘和归约按定宽回绕。浮点转整数采用饱和截断，NaN 转为 0，超范围值钳制到整数极值。除法保留独立除法运算；`negative` 由乘 -1、`subtract` 由加负数定义，按各基础操作分别舍入。浮点精度策略见 [ASK 数值语义](../../../ask/docs/ASK-IR与数值语义.md#cast-semantics)。

不同设备报 `RuntimeError`，同设备但属于不同 Engine 报 `ValueError`。主机条件可读取 `tolist()`；0-D 条件也可使用 `bool(x)`。追踪与融合过程见[自动合图](../architecture/张量模型与追踪机制.md#jit-specialization)。
