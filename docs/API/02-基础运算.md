# 02. 基础运算

<a id="operations"></a>

## 运算入口

以下接口返回待计算的 `Tensor`，读取结果或调用 `ft.evaluate` 时执行。

| 函数 | 等价写法 | 含义 |
| --- | --- | --- |
| `ft.add(x, y)` | `x + y` | 逐元素加法。 |
| `ft.subtract(x, y)` | `x - y` | 逐元素减法。 |
| `ft.multiply(x, y)` | `x * y` | 逐元素乘法。 |
| `ft.negative(x)` | `-x` | 逐元素取负。 |
| `ft.square(x)` | `x.square()` | 逐元素平方。 |
| `ft.cast(x, dtype)` | `x.astype(dtype)` | 显式转换元素类型，保持形状；如 `x.astype(ft.fp16)`。 |
| `ft.reshape(x, shape)` | `x.reshape(*shape)` | 保持元素次序，改变形状；[尺寸规则与示例](01-张量与数据交换.md#reshape)。 |
| `ft.zeros_like(x)` | — | 生成同形状、同 dtype、同设备的零张量。 |
| `ft.ones_like(x)` | — | 生成同形状、同 dtype、同设备的一张量。 |

二元运算至少有一个 Tensor。Tensor 与 Tensor 必须具有相同 shape、dtype 和设备；不同设备报 `RuntimeError`，同设备但属于不同独立 Engine 则报 `ValueError`。Python 数值字面量可放在任一侧，会按 Tensor 的 dtype 构造常量并扩展到相同形状；数值必须符合该类型的常量规则，不会自动把整数 Tensor 提升为浮点类型。

```python
import fugatensor as ft

x = ft.tensor([1, 2, 3], dtype=ft.int32)
y = ft.subtract(ft.square(x), 2 * x)
print(y.tolist())                  # [-1, 0, 3]
print((10 - x).tolist())           # [9, 8, 7]
print(x.astype(ft.fp32).tolist())  # [1.0, 2.0, 3.0]
```

<a id="types-and-limits"></a>

## 类型与支持边界

数值运算支持 `ft.int32`、`ft.int64`、`ft.fp32`、`ft.fp16`、`ft.bf16`。`ft.bool` 张量支持创建、读取、显式 cast、reshape 和 `zeros_like` / `ones_like`；布尔算术会报错。

`ft.int32`、`ft.int64` 加乘使用定宽回绕。浮点转整数采用饱和截断，NaN 转为 0、超范围值钳制到整数极值。浮点精度转换及自有计算的乘加策略见 [ASK 数值语义](../../../ask/docs/01-ASK-IR与数值语义.md#cast-semantics)。

尚未提供除法、幂、比较、索引、矩阵乘法或归约接口；`x == y` / `x != y` 会报错。需要主机判断时先读取 `tolist()` 的结果；0-D 条件也可使用 `bool(x)`。

普通 Python 函数可以直接组合这些运算；目前没有公开的 `ft.jit` 装饰器。运算的追踪与融合机制见[自动合图](../architecture/01-张量模型与追踪机制.md#jit-specialization)。
