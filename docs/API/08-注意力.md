# 08. 注意力

`ft.nn.functional.scaled_dot_product_attention` 计算缩放点积注意力。FlashAttention 的 kernel、启动配置和反向规则随 FugaTensor 包提供，调用方直接传入 Tensor，无需自行注册 Triton kernel。

<a id="scaled-dot-product-attention"></a>

## 1. 参数与结果

```text
ft.nn.functional.scaled_dot_product_attention(query, key, value, *, is_causal=False)
```

| 参数 | 约束 |
| --- | --- |
| `query` | 形状 `[B, H, M, D]` 的 Tensor |
| `key` | 形状 `[B, H, N, D]` 的 Tensor |
| `value` | 形状 `[B, H, N, DV]` 的 Tensor |
| `is_causal=False` | Python bool；为 `True` 时，查询行 `i` 只读取键列 `j <= i` |

三个输入必须是同一设备、同一引擎上的连续 CUDA 张量，GPU 要求 SM80 或更新架构，类型相同且为 `ft.fp16` 或 `ft.bf16`。各维须大于零，`D`、`DV` 各自取 32、64 或 128；`M` 与 `N` 可以不同，也不必是分块大小的整数倍。

返回形状 `[B, H, M, DV]`、类型与设备均与输入一致的待计算 Tensor。计算为 `softmax(Q @ Kᵀ / sqrt(D)) @ V`；因果掩码在非方阵上按左上角对齐。输入参与梯度记录时，结果可通过 `backward` 求出 Q、K、V 的一阶梯度，也可与普通 FugaTensor 运算继续组合。

<a id="example"></a>

## 2. 前向与反向

先完成 [CUDA 与 Triton 环境配置](../安装.md#configure-triton)，再直接调用：

```python
import fugatensor as ft

q = ft.ones(1, 2, 16, 32, dtype=ft.fp16, device="cuda", requires_grad=True)
k = ft.ones(1, 2, 24, 32, dtype=ft.fp16, device="cuda", requires_grad=True)
v = ft.ones(1, 2, 24, 64, dtype=ft.fp16, device="cuda", requires_grad=True)

output = ft.nn.functional.scaled_dot_product_attention(q, k, v, is_causal=True)
output.backward(ft.ones_like(output))
print(output.shape)  # (1, 2, 16, 64)
print(q.grad.shape, k.grad.shape, v.grad.shape)
# (1, 2, 16, 32) (1, 2, 24, 32) (1, 2, 24, 64)
```

注意力结果不是标量，调用 `backward` 时须提供同形状、同类型的梯度种子。前后运算可以直接写为 `scaled_dot_product_attention(q * 0.5, k, v) * 2`，它们保留在同一计算图中，并参与链式求导。

<a id="support-boundaries"></a>

## 3. 当前边界

该接口要求已配置 Triton worker；宿主进程不需要导入 Triton。CPU、`ft.fp32`、空维度及上述范围之外的特征宽度当前不受支持。通用张量创建仍默认 `ft.fp32`，使用注意力时需显式选择 `ft.fp16` 或 `ft.bf16`。

当前没有自定义 scale、dropout、加性 bias、外部 attention mask、分组查询注意力、变长序列或非连续 stride 参数。手写反向支持一阶微分，请求 `create_graph=True` 等高阶微分会被拒绝。

实现与执行计划见[ASK 桥接与多后端执行](../architecture/04-ASK桥接与多后端执行.md#cuda-and-triton)；精度、因果模式和形状的数值验证见[测试组织](../测试.md#attention-matrix)。
