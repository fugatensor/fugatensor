# 01. 张量与数据交换

<a id="tensor-create"></a>

## 创建张量

```text
ft.tensor(values, *, dtype=ft.fp32, shape=None, engine=None, device=None,
          requires_grad=False)
```

返回 `Tensor`，直接调用即可。例如 `ft.tensor([1, 2, 3])` 默认在 CPU 创建 fp32 张量，无需指定 `dtype`；需要整数、布尔或特定浮点精度时再传入 `ft.int32`、`ft.bool`、`ft.fp16` 等类型对象。`values` 接受 Python `bool`、`int`、`float` 或由它们组成的规则嵌套 list/tuple；不接受参差不齐的嵌套序列。

| 参数 | 行为 |
| --- | --- |
| `dtype` | 默认 `ft.fp32`，不按输入数据推断。传入下表的类型对象；布尔张量要求布尔值，整数张量要求范围内的 Python 整数。 |
| `shape` | 默认从嵌套结构推断。显式提供时按展平顺序填入新形状，元素总数必须匹配；不支持 `-1` 推断。 |
| `device` | 可选 `"cpu"`、`"cuda"`、`"cuda:N"`。省略时使用当前默认设备，初始为 CPU；可用 `ft.set_default_device(...)` 改变后续创建的默认值。 |
| `engine` | 高级选项，显式绑定一个 Engine；同时传入 `device` 时必须一致。普通用法无需创建或传入 Engine。 |
| `requires_grad` | 默认 `False`；只有 `ft.fp16`、`ft.bf16`、`ft.fp32` 可设为 `True`。 |

| 类型对象 | 元素类型 |
| --- | --- |
| `ft.bool` | 布尔值。 |
| `ft.int32` | 32 位有符号整数。 |
| `ft.int64` | 64 位有符号整数。 |
| `ft.fp32` | 32 位浮点，默认精度。 |
| `ft.fp16` | 16 位浮点。 |
| `ft.bf16` | bfloat16 浮点。 |

这些对象不可变且各自唯一，可用 `x.dtype is ft.fp32` 判断类型。`f32`、`i32` 等字符串是 IR 与序列化中的类型编码；Python API 使用上述对象。

```python
import fugatensor as ft

matrix = ft.tensor([1, 2, 3, 4], dtype=ft.int32, shape=(2, 2))
scalar = ft.tensor(3.0)
empty = ft.tensor([], shape=(0, 3))
assert scalar.dtype is ft.fp32
assert matrix.tolist() == [[1, 2], [3, 4]]
assert scalar.shape == () and scalar.tolist() == 3.0
assert empty.shape == (0, 3) and empty.tolist() == []
```

同一设备的普通张量共享自动管理的默认引擎，无需 `with` 或手动关闭。设备选择与高级 Engine 上下文的优先级见[设备与执行](03-设备与执行.md)。显式引擎也提供 `engine.tensor(values, *, dtype=ft.fp32, shape=None, requires_grad=False)`。

`ft.Tensor` 是返回值的类型，通常通过这些工厂创建；其直接构造函数需要后端存储对象，不是通用数组导入入口。浮点常量按目标精度舍入，数值规则见 [ASK 数值语义](../../../ask/docs/01-ASK-IR与数值语义.md#types-and-precision)。

<a id="tensor-inspect"></a>

## 属性与读取

| 接口 | 返回值与执行行为 |
| --- | --- |
| `x.shape`、`x.dtype`、`x.device` | 形状 tuple、类型对象（如 `ft.fp32`）、设备字符串；不求值。 |
| `x.engine` | 所属 `Engine`；跨引擎张量不能直接混合运算。 |
| `repr(x)` | 只显示元信息，不下载数据。 |
| `x.tolist()` | 按形状返回嵌套 list；0-D 返回 Python 标量。按需执行，CUDA 数据会复制回主机。 |
| `bool(x)` | 仅支持 `shape=()`，读取实际数值的真值，可用于普通 Python 的 `if` / `while`。 |
| `x.storage` | 按需求值后返回后端存储对象；CUDA 图提交后不保证已执行完毕。通用数据交换使用下述 buffer 接口。 |
| `x.requires_grad`、`x.grad`、`x.is_leaf` | 梯度相关只读属性，见[自动微分](04-自动微分与自定义函数.md)。 |

<a id="buffer-io"></a>

## 连续 buffer 导入与导出

```text
ft.from_buffer(data, *, dtype, shape, copy=True, engine=None, device=None,
               requires_grad=False)
x.to_buffer(*, copy=True)
```

导入返回 `Tensor`，设备选择与 `ft.tensor` 相同。原始字节无法说明元素类型，`dtype` 和 `shape` 必须显式指定，类型写为 `ft.int32` 等对象。`data` 须支持 Python buffer protocol 且为 C 连续布局，字节数等于元素数乘以 dtype 字节宽度。带元素类型的 buffer 须匹配 dtype 和本机字节序；bytes、bytearray 或单字节视图按原始位模式解释，不逐元素转换。`ft.bf16` 可用原始字节输入。显式引擎提供 `engine.from_buffer(data, *, dtype, shape, copy=True, requires_grad=False)`。

| 方式 | CPU | CUDA |
| --- | --- | --- |
| `from_buffer(..., copy=True)` | 创建自己的存储并批量复制。 | 批量上传到设备；当前主机传输会等待完成。 |
| `from_buffer(..., copy=False)` | 借用可写、对齐的连续存储，并保留其 owner；不接受只读来源。 | 不支持主机 buffer 的零复制导入。 |
| `to_buffer(copy=True)` | 返回独立快照的只读字节 `memoryview`。 | 等待计算、下载后返回只读字节 `memoryview`。 |
| `to_buffer(copy=False)` | 返回底层存储的只读字节视图，视图保留存储寿命。 | 不支持。 |

借用和只读视图都不冻结原存储；其他持有者修改内存时，视图内容随之变化。借用输入在待计算图和反向图仍可能读取它期间应保持内容稳定。

```python
from array import array
import fugatensor as ft

values = array("i", [1, 2, 3])
x = ft.from_buffer(values, dtype=ft.int32, shape=(3,), copy=False)
values[0] = 7
assert x.tolist() == [7, 2, 3]
data = x.to_buffer()
assert data.readonly and data.format == "B"
restored = ft.from_buffer(data, dtype=ft.int32, shape=(3,))
assert restored.tolist() == [7, 2, 3]
```

底层存储与寿命说明见[张量模型](../architecture/01-张量模型与追踪机制.md#buffer-io)。buffer 接口不会保存 dtype/shape 元信息，持久化完整权重树请使用[权重读写](06-权重读写.md)。
