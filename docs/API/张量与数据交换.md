# 张量与数据交换

<a id="tensor-create"></a>

## 创建张量

```text
ft.tensor(data, *, dtype=ft.fp32, engine=None, device=None,
          requires_grad=False)
```

返回 `Tensor`，直接调用即可。例如 `ft.tensor([1, 2, 3])` 默认在 CPU 创建 fp32 张量，无需指定 `dtype`。`data` 接受 Python `bool`、`int`、`float` 或规则嵌套 list/tuple，形状由数据推断；改变形状使用下文的 `reshape`。

| 参数 | 行为 |
| --- | --- |
| `dtype` | 默认 `ft.fp32`，不按输入数据推断。传入下表的类型对象；布尔张量要求布尔值，整数张量要求范围内的 Python 整数。 |
| `device` | 接受 `ft.device(...)` 对象或 `"cpu"`、`"cuda"`、`"cuda:N"`。省略时使用当前默认设备，初始为 CPU。 |
| `engine` | 高级选项，显式绑定一个 Engine；同时传入 `device` 时必须一致。普通用法无需创建或传入 Engine。 |
| `requires_grad` | 默认 `False`；只有 `ft.fp16`、`ft.bf16`、`ft.fp32` 可设为 `True`。 |

| 类型对象 | 元素类型 |
| --- | --- |
| `ft.bool` | 布尔值。 |
| `ft.int32` | 32 位有符号整数。 |
| `ft.int64` | 64 位有符号整数。 |
| `ft.fp32` | 32 位浮点，默认精度。 |
| `ft.fp16` | 16 位浮点。 |
| `ft.bf16` | bfloat16 浮点。 |

这些对象不可变且各自唯一，可用 `x.dtype is ft.fp32` 判断类型。`f32`、`i32` 等字符串是 IR 与序列化中的类型编码；Python API 使用上述对象。

```python
import fugatensor as ft

matrix = ft.tensor([[1, 2], [3, 4]])
scalar = ft.tensor(3.0)
print(matrix.tolist())  # [[1.0, 2.0], [3.0, 4.0]]
print(scalar.tolist())  # 3.0
```

同一设备的普通张量共享自动管理的默认引擎，无需 `with` 或手动关闭。设备选择与高级 Engine 上下文的优先级见[设备与执行](设备与执行.md)。显式引擎也提供 `engine.tensor(...)` 创建入口。

`ft.Tensor` 是返回值的类型，通常通过这些工厂创建；其直接构造函数需要后端存储对象，不是通用数组导入入口。浮点常量按目标精度舍入，数值规则见 [ASK 数值语义](../../../ask/docs/ASK-IR与数值语义.md#types-and-precision)。

<a id="size-factories"></a>

## 按尺寸创建

| 接口 | 内容 |
| --- | --- |
| `ft.zeros(*size, dtype=ft.fp32, device=None, requires_grad=False)` | 指定尺寸的全零张量。 |
| `ft.ones(*size, dtype=ft.fp32, device=None, requires_grad=False)` | 指定尺寸的全一张量。 |
| `ft.empty(*size, dtype=ft.fp32, device=None, requires_grad=False)` | 分配存储，不保证元素初值。 |
| `ft.full(size, fill_value, *, dtype=ft.fp32, device=None, requires_grad=False)` | 指定尺寸的填充值张量。 |

尺寸可写为 `ft.zeros(2, 2)`、`ft.zeros((2, 2))` 或 `ft.zeros([2, 2])`，各维必须为非负整数。`ft.full` 的尺寸作为单个 tuple/list 传入；`fill_value` 须符合所选 dtype 的常量规则。这些工厂返回新 Tensor，类型、设备和求导选项与 `ft.tensor` 一致；指定 `()` 创建 0-D 张量，某一维为 0 创建空张量。

```python
import fugatensor as ft

zeros = ft.zeros(2, 2)
ones = ft.ones(2, 2)
filled = ft.full((2, 2), 3)
empty = ft.empty(0, 3)
print((zeros + ones + filled).tolist())  # [[4.0, 4.0], [4.0, 4.0]]
print(empty.shape)                       # (0, 3)
```

<a id="reshape"></a>

## 改变形状

`x.reshape(*shape)` 和 `ft.reshape(x, shape)` 返回同 dtype、同设备、相同元素次序的新 Tensor。方法可接收多个尺寸或一个 tuple/list；函数形式接收一个 tuple/list。总元素数必须保持不变，可用一个 `-1` 推断该维长度。

```python
import fugatensor as ft

x = ft.tensor([1, 2, 3, 4])
matrix = x.reshape(2, 2)
flat = matrix.reshape(-1)
column = ft.reshape(x, (4, 1))
print(matrix.tolist())  # [[1.0, 2.0], [3.0, 4.0]]
print(flat.shape)       # (4,)
print(column.shape)     # (4, 1)
```

reshape 只组图，不立即执行；可与后续算术一起编译，也可参与自动微分。零元素可以重排为显式零尺寸；`reshape(-1)` 可推断为 `(0,)`，但 `reshape(0, -1)` 的推断不唯一，会报错。当前只支持连续张量，不提供 `view`，也不承诺 reshape 与输入共享存储。

<a id="tensor-inspect"></a>

## 属性与读取

| 接口 | 返回值与执行行为 |
| --- | --- |
| `x.shape`、`x.dtype`、`x.device` | 形状 tuple、类型对象（如 `ft.fp32`）、实际设备对象（如 `ft.device("cuda", 0)`）；不求值。 |
| `x.engine` | 所属 `Engine`；跨引擎张量不能直接混合运算。 |
| `repr(x)` | 只显示元信息，不下载数据。 |
| `x.tolist()` | 按形状返回嵌套 list；0-D 返回 Python 标量。按需执行，CUDA 数据会复制回主机。 |
| `bool(x)` | 仅支持 `shape=()`，读取实际数值的真值，可用于普通 Python 的 `if` / `while`。 |
| `x.storage` | 按需求值后返回后端存储对象；CUDA 图提交后不保证已执行完毕。通用数据交换使用下述 buffer 接口。 |
| `x.requires_grad`、`x.grad`、`x.is_leaf` | 梯度相关只读属性，见[自动微分](自动微分与自定义函数.md)。 |

<a id="buffer-io"></a>

## 连续 buffer 导入与导出

```text
ft.from_buffer(data, *, dtype, shape, copy=True, engine=None, device=None,
               requires_grad=False)
x.to_buffer(*, copy=True)
```

导入返回 `Tensor`，设备选择与 `ft.tensor` 相同。原始字节无法说明元素类型，`dtype` 和 `shape` 必须显式指定，类型写为 `ft.int32` 等对象。`data` 须支持 Python buffer protocol 且为 C 连续布局，字节数等于元素数乘以 dtype 字节宽度。带元素类型的 buffer 须匹配 dtype 和本机字节序；bytes、bytearray 或单字节视图按原始位模式解释，不逐元素转换。`ft.bf16` 可用原始字节输入。显式引擎提供 `engine.from_buffer(data, *, dtype, shape, copy=True, requires_grad=False)`。

| 方式 | CPU | CUDA |
| --- | --- | --- |
| `from_buffer(..., copy=True)` | 创建自己的存储并批量复制。 | 批量上传到设备；当前主机传输会等待完成。 |
| `from_buffer(..., copy=False)` | 借用可写、对齐的连续存储，并保留其 owner；不接受只读来源。 | 不支持主机 buffer 的零复制导入。 |
| `to_buffer(copy=True)` | 返回独立快照的只读字节 `memoryview`。 | 等待计算、下载后返回只读字节 `memoryview`。 |
| `to_buffer(copy=False)` | 返回底层存储的只读字节视图，视图保留存储寿命。 | 不支持。 |

借用和只读视图都不冻结原存储；其他持有者修改内存时，视图内容随之变化。借用输入在待计算图和反向图仍可能读取它期间应保持内容稳定。

```python
from array import array
import fugatensor as ft

values = array("i", [1, 2, 3])
x = ft.from_buffer(values, dtype=ft.int32, shape=(3,), copy=False)
values[0] = 7
data = x.to_buffer()
restored = ft.from_buffer(data, dtype=ft.int32, shape=(3,))
print(restored.tolist())  # [7, 2, 3]
```

底层存储与寿命说明见[张量模型](../architecture/张量模型与追踪机制.md#buffer-io)。buffer 接口不会保存 dtype/shape 元信息，持久化完整权重树请使用[权重读写](权重读写.md)。
