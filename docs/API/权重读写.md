# 权重读写

`ft.weights` 把嵌套 Tensor 容器保存为目录，加载时恢复容器结构、张量形状、dtype 和数据。模型类、计算图和训练过程由应用管理。

<a id="save-load"></a>
## 保存与加载

| 接口 | 返回值 |
| --- | --- |
| `ft.weights.save(directory, tree, *, metadata=None, overwrite=False)` | 保存成功后返回目标目录的 `pathlib.Path`。 |
| `ft.weights.load(directory, *, engine=None, device=None)` | 返回恢复后的 Tensor 容器；根节点也可以直接是 Tensor。 |
| `ft.save_weights(...)` | `ft.weights.save` 的顶层别名，参数与返回值相同。 |
| `ft.load_weights(...)` | `ft.weights.load` 的顶层别名，参数与返回值相同。 |

`ft.weights.export` 也是 `save` 的别名。`directory` 接受字符串或路径对象。

保存时先求值并读取张量，须在所属引擎关闭前完成。目标目录已存在时，传 `overwrite=True` 才能覆盖。`metadata` 默认为空字典，接受可 JSON 序列化的映射，排除 NaN、Infinity 和 Tensor。

加载使用当前默认设备，也可用 `device="cuda"` 或 `engine` 指定，规则见[设备选择](设备与执行.md)。包含 bf16 的权重选择 CUDA 设备。恢复的张量是独立数据输入；后续浮点表达式通过 `ft.grad` 对选定张量求导。

<a id="weight-tree"></a>
## 容器与数据边界

- 叶子必须是 Tensor；容器支持字符串键映射、list 和 tuple，允许任意嵌套，不能有循环引用。映射键必须是非空字符串，加载后恢复为普通 dict；list 与 tuple 保留各自类型。
- 支持 `ft.bool`、`ft.int32`、`ft.int64`、`ft.fp32`、`ft.fp16`、`ft.bf16`，保留张量形状和数值。普通标量、训练步数等非 Tensor 信息放在 `metadata` 中；manifest 内使用稳定的字符串类型编码。
- 相同数据在文件中去重，加载后各叶子使用独立 Tensor 和存储。
- 浮点数据按数值编码；若依赖 NaN 的特定位模式，权重接口不保证保留其 payload。

<a id="weight-example"></a>
## CPU 示例

```python
from pathlib import Path
from tempfile import TemporaryDirectory
import fugatensor as ft

with TemporaryDirectory() as directory:
    tree = {
        "weight": ft.tensor([1.0, 2.0]),
        "state": (ft.tensor(3, dtype=ft.int32),),
    }
    path = ft.save_weights(
        Path(directory) / "checkpoint", tree, metadata={"step": 3}
    )
    loaded = ft.load_weights(path)
    print(loaded["weight"].tolist())       # [1.0, 2.0]
    print(loaded["state"][0].tolist())     # 3，state 仍为 tuple
    print(ft.weights.read_metadata(path))  # {'step': 3}
```

<a id="inspect-errors"></a>
## 查看清单与处理错误

| 接口 | 返回值与边界 |
| --- | --- |
| `ft.weights.read_manifest(directory)` | 返回经过格式校验的 manifest 字典副本，不读取数组数据，也不分配 Tensor。 |
| `ft.weights.read_metadata(directory)` | 返回 manifest 中的用户 metadata 字典；没有时为空字典，同样不读取数组数据。 |
| `ft.weights.WeightsError` | `ValueError` 的子类，表示权重包不完整、格式不合法或数据校验失败。 |

`load()` 除了检查清单，还校验数组长度与内容摘要。`read_manifest()` 和 `read_metadata()` 只检查清单。参数类型错误、目录已存在和系统 I/O 错误分别按情况抛出 `TypeError`、`FileExistsError` 或 `OSError`。

目录内容与版本规则见[存储布局](../architecture/权重格式与导出.md#weight-layout)，完整性检查见[权重校验](../architecture/权重格式与导出.md#weight-validation)。
