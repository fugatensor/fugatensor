# 测试组织与覆盖矩阵

API 示例写在文档中，用合法代码展示调用与结果。测试位于 `tests/`，用断言检查数值、梯度和契约；生产算子位于 `src/fugatensor/`。测试直接调用生产 API，数值参考和输入生成放在测试支持模块中。

<a id="running"></a>

## 1. 运行范围

使用已经安装 `_native` 扩展的虚拟环境：

```bash
# CPU、Fuga IR、原生图分析与接口契约
.venv/bin/python -m unittest -v

# 同时覆盖物理 GPU 自有计算、Triton 和内置注意力
FUGATENSOR_TEST_CUDA=1 FUGATENSOR_TEST_TRITON=1 .venv/bin/python -m unittest -v
```

`tests/_helpers.py` 的 `EngineTestCase` 为每个测试类管理引擎与临时缓存。CPU 与 CUDA 共用基础算子矩阵；GPU 需显式启用，缺少工具、驱动或精度能力造成的跳过须单独记录。

后端协议、缓存和底层数值测试位于 `tests/backend/`，物理 GPU 后端测试位于 `tests/backend/gpu/`。完整命令见[工程约定](../AGENTS.md)；底层舍入、饱和转换等边界复用 `tests/backend/support/pointwise.py` 的独立参考与 `plan_matrix`。

<a id="operation-matrix"></a>

## 2. 基础 API 组合矩阵

[`tests/support/ops_matrix.py`](../tests/support/ops_matrix.py) 的 `OPERATIONS` 注册每个 API 的调用方式、独立参考表达式和适用类型。`plan_matrix()` 自动生成按序组合，再与 dtype、求导阶数交叉。默认覆盖单算子和所有连续两层组合；共同输入为两个张量，每一层消费前一层结果及第二个输入，单输入算子只消费前一层结果。

[`tests/test_ops_matrix.py`](../tests/test_ops_matrix.py) 共用一套断言检查形状、类型、前向值、一阶偏导和全部二阶偏导，包括混合偏导。参考使用独立二元多项式和精确分数求导，不调用被测自动微分实现。常数路径与未使用输入的梯度也被检查。相同精度的多个组合批量求值，减少重复编译与提交。

| 环境变量 | 可选值与默认行为 |
| --- | --- |
| `FUGATENSOR_TEST_OPS` | 逗号分隔的注册名；默认全部：`add,subtract,multiply,negative,square,reshape,cast,zeros_like,ones_like` |
| `FUGATENSOR_TEST_DEPTHS` | `1,2,3` 的子集；默认 `1,2` |
| `FUGATENSOR_TEST_DTYPES` | `fp32,fp16,bf16,int32,int64,bool` 的子集；默认全部，按算子适用类型筛选 |
| `FUGATENSOR_TEST_ORDERS` | `0,1,2,3` 的子集；默认 `0,1,2`，整数和 bool 只检查前向 |

只复现乘法、平方及它们的两层组合，检查 fp16 前向和一阶导数：

```bash
FUGATENSOR_TEST_OPS=multiply,square \
FUGATENSOR_TEST_DEPTHS=2 \
FUGATENSOR_TEST_DTYPES=fp16 \
FUGATENSOR_TEST_ORDERS=0,1 \
.venv/bin/python -m unittest -v tests.test_ops_matrix.HostOperationMatrixTests
```

切换到 GPU 时将测试类改为 `CUDAOperationMatrixTests`，并增加 `FUGATENSOR_TEST_CUDA=1`。筛选值须使用注册名，空值和未知名称直接报错，避免拼写错误导致漏测。

新增适用的基础算子时，给 `OPERATIONS` 增加一项调用和独立参考即可纳入所有组合、精度与导数阶数。当前参考覆盖多项式运算及保持数值的形状/类型变换；引入非多项式算子时须补充对应的独立参考。共享分支、多输出、梯度累加、资源寿命、缓存和异常契约由各专题测试负责。

<a id="attention-matrix"></a>

## 3. 注意力矩阵

[`tests/test_attention.py`](../tests/test_attention.py) 直接调用[attention API](API/attention.md)。默认交叉 `fp16/bf16`、三类形状、两种因果模式以及直接调用/前后缩放组合，共 24 个配置；每个配置都检查前向、Q/K/V 一阶梯度、形状、精度和执行计划。[`tests/support/attention.py`](../tests/support/attention.py) 维护独立的主机数值参考与反向公式，生产包不依赖它。

| 环境变量 | 可选值与默认行为 |
| --- | --- |
| `FUGATENSOR_TEST_DTYPES` | 与基础矩阵共用；注意力默认 `fp16,bf16`，只执行该 API 支持的类型 |
| `FUGATENSOR_TEST_ATTENTION_SHAPES` | 默认 `tail,wide,batched`，分别覆盖分块尾部、不等特征宽度、多 batch/多 head |
| `FUGATENSOR_TEST_ATTENTION_CAUSAL` | 默认 `false,true` |
| `FUGATENSOR_TEST_ATTENTION_COMPOSITIONS` | 默认 `plain,scaled`；`scaled` 同时加入查询输入缩放与输出缩放 |

只检查一个注意力配置：

```bash
FUGATENSOR_TEST_TRITON=1 \
FUGATENSOR_TEST_DTYPES=fp16 \
FUGATENSOR_TEST_ATTENTION_SHAPES=tail \
FUGATENSOR_TEST_ATTENTION_CAUSAL=true \
FUGATENSOR_TEST_ATTENTION_COMPOSITIONS=scaled \
.venv/bin/python -m unittest -v tests.test_attention.AttentionCUDAExecutionTests
```

输入契约另由 CPU 可运行的 `AttentionContractTests` 检查，包括不支持的设备、类型、维度、零尺寸与因果参数；GPU 测试还检查高阶微分在编译和梯度写入前被拒绝。
