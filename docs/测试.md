# 测试组织与覆盖矩阵

测试位于 `tests/`，调用公开 API 检查数值、梯度和异常。输入生成与数值参考放在测试支持模块中。

Fuga 与 Torch 的执行时间通过[独立性能记录脚本](PyTorch性能对照.md)对比，生成负载矩阵并在计时外检查数值。

<a id="running"></a>

## 1. 运行范围

在安装好的开发环境中运行：

```bash
# CPU、Fuga IR、原生图分析与接口契约
.venv/bin/python -m unittest -v

# 同时覆盖物理 GPU 自有计算、Triton 和内置注意力
FUGATENSOR_TEST_CUDA=1 FUGATENSOR_TEST_TRITON=1 .venv/bin/python -m unittest -v
```

`EngineTestCase`（`tests/_helpers.py`）为每个测试类管理引擎和临时缓存。CPU、CUDA 共用算子矩阵，GPU 测试由环境变量启用。缺少工具、驱动或精度支持而跳过的用例须单独记录。

wheel 安装测试分别为 pure、all 创建虚拟环境，检查 pip 依赖安装、CPU 数值、梯度和 worker 选择。启用 GPU 后还会执行 all 的 Triton kernel：

```bash
FUGATENSOR_TEST_WHEEL=/absolute/path/to/fugatensor.whl \
FUGATENSOR_TEST_TRITON=1 \
.venv/bin/python -m unittest discover -s tests/packaging -v
```

[`tests/packaging/test_installation.py`](../tests/packaging/test_installation.py) 单独运行，all 的依赖由 pip 从包源安装。仅检查 CPU 安装时省略 `FUGATENSOR_TEST_TRITON`。

协议、缓存和底层数值测试位于 `tests/backend/`，GPU 后端测试位于 `tests/backend/gpu/`。命令见[工程约定](../AGENTS.md)。舍入和饱和转换用例共用 `tests/backend/support/pointwise.py` 的参考实现与 `plan_matrix`。

<a id="operation-matrix"></a>

## 2. 基础 API 组合矩阵

[`tests/support/ops_matrix.py`](../tests/support/ops_matrix.py) 的 `OPERATIONS` 注册每个 API 的调用方式、独立参考表达式和适用类型。`plan_matrix()` 自动生成按序组合，再与 dtype、shape、求导阶数交叉。默认覆盖单算子和所有连续两层组合；共同输入为两个张量，每一层消费前一层结果及第二个输入，单输入算子只消费前一层结果。

[`tests/test_ops_matrix.py`](../tests/test_ops_matrix.py) 检查形状、类型、前向值、一阶偏导和包含混合项的二阶偏导，也覆盖常数路径及未使用输入的梯度。参考结果通过二元多项式和精确分数求导计算。相同精度和形状的组合批量求值，以减少编译和提交次数。形状轴覆盖标量、向量、矩阵、单例维度和空张量；reshape 使用当前 shape 自动生成往返变换。

| 环境变量 | 可选值与默认行为 |
| --- | --- |
| `FUGATENSOR_TEST_OPS` | 逗号分隔的注册名；默认全部：`add,subtract,multiply,negative,square,reshape,cast,zeros_like,ones_like` |
| `FUGATENSOR_TEST_DEPTHS` | `1,2,3` 的子集；默认 `1,2` |
| `FUGATENSOR_TEST_DTYPES` | `fp32,fp16,bf16,int32,int64,bool` 的子集；默认全部，按算子适用类型筛选 |
| `FUGATENSOR_TEST_SHAPES` | `scalar,vector,matrix,singleton,empty` 的子集；默认全部 |
| `FUGATENSOR_TEST_ORDERS` | `0,1,2,3` 的子集；默认 `0,1,2`，整数和 bool 只检查前向 |

只复现乘法、平方及它们的两层组合，检查 fp16 前向和一阶导数：

```bash
FUGATENSOR_TEST_OPS=multiply,square \
FUGATENSOR_TEST_DEPTHS=2 \
FUGATENSOR_TEST_DTYPES=fp16 \
FUGATENSOR_TEST_ORDERS=0,1 \
.venv/bin/python -m unittest -v tests.test_ops_matrix.HostOperationMatrixTests
```

切换到 GPU 时将测试类改为 `CUDAOperationMatrixTests`，并增加 `FUGATENSOR_TEST_CUDA=1`。筛选值须使用注册名，空值和未知名称直接报错，避免拼写错误导致漏测。

新增基础算子时，在 `OPERATIONS` 中添加调用和参考表达式，即可进入组合矩阵。当前参考覆盖多项式运算及保持数值的形状、类型变换；非多项式算子须补充参考方法。共享分支、多输出、重复求导、资源寿命、缓存和异常由专题测试覆盖。

CUDA Array Interface 的存储矩阵由 `tests/backend/support/storage_matrix.py` 生成，交叉五种 CAI 类型、五种形状和隐式连续、显式连续、带间隔三种 stride 描述。断言检查合法描述的解析结果与非连续存储的拒绝。

GPU 参数 ABI 探针在 `tests/backend/support/scalar_abi.py` 生成独立 PTX，覆盖各宽度的标量、对齐后的指针与 null；同一探针交叉 PTX/cubin 和 stream/Graph 启动，检查精确位模式、冻结常量和公开端口地址更新。

## 3. 注意力矩阵

[`tests/test_attention.py`](../tests/test_attention.py) 调用 [attention API](API/attention.md)，交叉 fp16/bf16、三类形状、两种因果模式和两种前后算子组合，共 24 个配置。每个配置检查前向值、Q/K/V 一阶梯度、形状、精度和执行计划；数值参考和反向公式见 [`tests/support/attention.py`](../tests/support/attention.py)。

| 环境变量 | 可选值与默认行为 |
| --- | --- |
| `FUGATENSOR_TEST_DTYPES` | 与基础矩阵共用；注意力默认 `fp16,bf16`，只执行该 API 支持的类型 |
| `FUGATENSOR_TEST_ATTENTION_SHAPES` | 默认 `tail,wide,batched`，分别覆盖分块尾部、不等特征宽度、多 batch/多 head |
| `FUGATENSOR_TEST_ATTENTION_CAUSAL` | 默认 `false,true` |
| `FUGATENSOR_TEST_ATTENTION_COMPOSITIONS` | 默认 `plain,scaled`；`scaled` 同时加入查询输入缩放与输出缩放 |

只检查一个注意力配置：

```bash
FUGATENSOR_TEST_TRITON=1 \
FUGATENSOR_TEST_DTYPES=fp16 \
FUGATENSOR_TEST_ATTENTION_SHAPES=tail \
FUGATENSOR_TEST_ATTENTION_CAUSAL=true \
FUGATENSOR_TEST_ATTENTION_COMPOSITIONS=scaled \
.venv/bin/python -m unittest -v tests.test_attention.AttentionCUDAExecutionTests
```

输入契约另由 CPU 可运行的 `AttentionContractTests` 检查，包括不支持的设备、类型、维度、零尺寸与因果参数；GPU 测试还检查缺少规则的高阶微分在构造导数图时被拒绝。

## 张量原语与矩阵乘法矩阵

`tests/support/tensor_primitives.py` 生成 dtype × shape × permutation/axes × device 组合，独立行主序索引参考校验广播、转置、比较、选择与归约。`tests/test_tensor_primitives.py` 同时检查初等函数、JVP、VJP、二阶导数及融合区域数量。

矩阵乘法使用 3 种浮点 dtype、4 种批形状、5 组 M/N/K 和 4 组转置标志，生成每设备 240 项配置，包含空 M/N/K 与零批次。独立索引参考验证数值，梯度矩阵覆盖转置、批维度和交叉二阶导数。CUDA 检查库调用步骤、矩阵乘法两侧逐元素融合，以及普通 stream 和 Graph 执行。

```bash
FUGATENSOR_TEST_CUDA=1 .venv/bin/python -m unittest -v tests.test_tensor_primitives
```

`FUGATENSOR_TEST_DTYPES` 同时控制此矩阵的 dtype 轴；CPU 数值矩阵根据 `host_supported_element_types` 选择五种类型，bf16 独立断言编译期拒绝；CUDA 执行 bf16 数值验证。

CPU 临时区接入矩阵交叉 4 种可归约 dtype、3 种行数、2 种列数、2 种归约扩展深度、转置布局和中间值公开输出，生成 192 项，覆盖空张量和单元素 SSA。另有 5 × 5 种类型转换与标量提前捕获组合，共 50 项，验证跨类型槽位和 SSA 保活。独立 Python 数值参考验证完整用户 API 路径。GPU 原生分支矩阵交叉分支数、链深度和 stream/Graph 模式，检查数值、已保留输出、变址重放、依赖边数及内部工作区容量；ASK 的原生矩阵补充静态非法计划和 cuBLASLt scratch 覆盖。


<a id="storage-matrix"></a>

## 张量创建与存储矩阵

`tests/support/storage.py` 按 dtype × shape × 创建入口生成组合；`tests/test_tensor_storage.py` 检查 CPU 五种 dtype、CPU bf16 创建拒绝、CUDA 六种 dtype、原始字节保真与复制契约。GPU 创建直接使用设备存储，创建矩阵同时检查编译次数保持不变。BF16 计算与权重往返在支持该精度的 CUDA 设备执行。

```bash
FUGATENSOR_TEST_CUDA=1 .venv/bin/python -m unittest -v tests.test_tensor_storage tests.test_weights
```
