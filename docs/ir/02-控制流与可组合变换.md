## 1. 两类控制流路径

| 机制 | 产生方式 | 编译与求导行为 |
| --- | --- | --- |
| **IR 级结构化区域**（`fuga.if` / `fuga.for` / `fuga.while`） | 通过 `Function` / `BlockBuilder` 显式构造 | 保存在 Fuga IR 的嵌套 `Region` 中。当 `if` 条件在编译期可折叠为布尔常量、或 `for` 具有有界静态起止步长时，支持直接做 IR 级 `vjp` 求导并在 [`lower_to_ask`](03-降级到ASK.md#static-simplification) 中展开为单块 ASK 图；动态未决的 `if`/`while` 区域在降级边界报错拒绝。 |
| **Python 标量条件边界**（[按需执行](../architecture/01-张量模型与追踪机制.md#graph-break)） | 普通 Python 中对 0-D Tensor 执行 `if cond:` / `while cond:` | 读取条件真值时编译并执行其依赖图，Python 按实际分支与循环次数继续构建 Tensor 表达式；各阶段的梯度历史保持连接。自定义 `ft.fun` 的隔离追踪不支持这类数据依赖控制流。 |

<a id="primitive-registry"></a>

## 2. 原语规则表（`ir/primitives.py`）

基础算子在 `PRIMITIVE_RULES` 注册表中声明三条规则（`PrimitiveRule`）：

1. **`abstract_eval(input_types, attrs)`**：根据输入类型与语义属性推导输出类型 tuple 并校验参数，支持标量与张量。追踪、验证与变换构建器共用同一份推导逻辑。
2. **`jvp(builder, operation, primals, tangents)`**：前向切线传播规则。接收原值 `primals` 与对应切线 `tangents`（无需微分的端口为 `None`），发出切线指令：
   - `constant` → `None`；
   - `splat(x)` → 若 `dx` 存在则生成 `splat(dx, shape)`；
   - `add(a, b)` → `da + db`（单侧为 `None` 时直接返回另一侧）；
   - `mul(a, b)` → `da * b + a * db`；
   - `cast(x, to=T)` → 原值与目标均为可微浮点（`FLOAT_DTYPES`）时生成 `cast(dx, to=T)`；求导路径跨越非浮点类型时报错。
   - `reshape(x, shape)` → 将 `dx` 改为输出形状。
3. **`vjp(builder, operation, primals, cotangent, active)`**：反向余切传播规则，`active` 指示需要梯度的输入：
   - `add(a, b)` → `(dout, dout)`；
   - `mul(a, b)` → `(dout * b, dout * a)`；
   - `splat(x)` → 活跃标量输入的反向规则尚未实现，会报错；常量系数支路无需对其求导；
   - `cast(x, to=T)` → 可微浮点之间生成 `cast(dout, to=x.dtype)`，求导路径跨整数或布尔时报错；
   - `reshape(x, shape)` → 将 `dout` 恢复为 `x.shape`。

上述 `jvp` 与 `vjp` 规则生成的指令仍全部属于 `constant`、`splat`、`add`、`mul`、`cast`、`reshape` 六种基础原语，因此微分后的 `Module` 可以继续作为 `jvp`、`vjp`、`prune` 或 `lower_to_ask` 的输入。

<a id="jvp-and-vjp"></a>

## 3. `ir.jvp` 与 `ir.vjp` 图级变换（`ir/jvp.py` / `ir/differentiate.py`）

两个模块级变换均返回新 `Module`，不原地修改输入：

- **前向模式 `jvp(module, argnums=...)`**：
  生成输入为 `(*primals, *selected_tangents)`、输出为 `(*primal_outputs, *output_tangents)` 的新函数。先化简静态区域，再调用 C++ [`analyze_function`](../architecture/02-原生图分析与C++边界.md#native-analyze) 获取活跃子图，按正向拓扑序同步构造原值与切线；活跃路径上的 `fuga.call` 或外部算子缺少显式 JVP 规则时会报错。最后调用 `prune` 移除未使用的中间节点。
- **反向模式 `vjp(module, argnums=...)`**：
  生成输入为 `(*primals, *output_cotangent_seeds)`、输出对应 `argnums` 所选可微输入梯度的新函数：
  1. 对静态可知的 `if`/`for` 执行控制流化简展开，使循环内的正向激活值成为显式 SSA 值；
  2. 调用 C++ `analyze_function` 获取 `reverse_ops`，排除与所选输入或目标输出无关的分支与旁路副作用算子；
  3. 重放所需的正向计算，按 `reverse_ops` 逆拓扑序累积各 SSA 值的余切（同一 SSA 值被多处消费时插入 `fuga.add` 累加；带自定义反向的 `fuga.call` 内联其 `backward` 模块并接入正向 `saved` 端口；未收到路径贡献的可微输入补齐对应零张量）；
  4. 调用 `prune` 移除反向图中不再需要的正向计算（如 `f(x) = 3 * x` 的反向图剪枝后不再读取 `x`）。

`tests/test_ir_autodiff.py` 对 `vjp(jvp(f))` 与 `jvp(vjp(f))` 在 ASK 上的编译执行结果做了一致性核对。
