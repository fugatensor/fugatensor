# 02. 控制流与可组合变换

返回 IR 总览：[结构化控制流与可组合微分](README.md#ir-control-transforms) · 相关细节：[对象模型与验证](01-对象模型与验证.md) · [降级到 ASK](03-降级到ASK.md) · [自动微分与自定义算子](../architecture/03-自动微分与自定义算子.md)

本章拆解 FugaTensor 中控制流的两种表达路径，以及原语规则表如何驱动前向微分（`jvp`）与反向微分（`vjp`）自由组合。

<a id="structured-control-flow"></a>

## 1. 两条互补的控制流路径

在 FugaTensor 中，“IR 级结构化控制流”与“Python 运行时图中断”各司其职，不要把两者混为一谈：

| 机制 | 产生方式 | 编译与求导行为 |
| --- | --- | --- |
| **IR 级结构化区域**（`fuga.if` / `fuga.for` / `fuga.while`） | 通过 `FunctionBuilder` 显式构造 | 完整保留在 Fuga IR 的嵌套 `Region` 中。当 `if` 条件在编译期可静态折叠为布尔常量、或 `for` 具有有界静态起止步长时，支持直接做 IR 级 `vjp` 求导并在 [`lower_to_ask`](03-降级到ASK.md#static-simplification) 中无损展开为单块 ASK 图；动态未决的 `if`/`while` 区域因当前 ASK 只接收单基本块静态图而在降级边界明确拒绝。 |
| **Python 运行时图中断**（[Graph Break](../architecture/01-张量模型与追踪机制.md#graph-break)） | 普通 `@ft.jit` 函数中对 0-D 标量张量执行 `if cond:` / `while cond:` | 追踪器在运行时先执行前缀图、读回标量真值，再按实际走过的分支与循环轮数动态调度多个单块静态 Fuga IR 片段，并通过运行时 `GradHistory` 把各片段串联成完整的反向传播链（支持一阶及高阶求导）。 |

<a id="primitive-registry"></a>

## 2. 闭合原语规则表（`ir/primitives.py`）

所有基础算子都在 `PRIMITIVES` 注册表中集中声明三条纯函数规则（`PrimitiveSpec`）：

1. **`abstract_eval(*in_types, **attrs) -> tuple[TensorType, ...]`**：仅根据输入 `TensorType` 与属性推导输出类型并做合法性校验。追踪、验证与变换构建器都共享这同一份类型推导源。
2. **`jvp(builder, primals, tangents, attrs, results)`**：前向切线传播规则。输入原值 `primals` 与对应切线 `tangents`（无需微分的端口切线为 `None`），用同一个 `BlockBuilder` 发出切线计算指令：
   - `constant` → 切线恒为 `None`（零导数无需实例化冗余零张量）；
   - `splat(x)` → 若 `dx` 存在则 `splat(dx, shape)`；
   - `add(a, b)` → `da + db`（单侧为 `None` 时直接透传另一侧）；
   - `mul(a, b)` → 莱布尼茨乘法法则 `da * b + a * db`；
   - `cast(x, to=T)` → 若原值与目标均为可微浮点（`FLOAT_DTYPES`），切线同步执行 `cast(dx, to=T)`；一旦跨越非浮点类型（如 `f32 -> i32 -> f32`），导数链路立即切断为 `None`。
3. **`vjp(builder, primals, cotangents, attrs, results)`**：反向伴随（余切）传播规则：
   - `add(a, b)` → `(dout, dout)`；
   - `mul(a, b)` → `(dout * b, dout * a)`；
   - `splat(x)` → 仅在 0-D 标量恒等 `splat` 时透传 `dout`（非标量 `splat` 的逆向需要归约求和，当前在无归约算子阶段只在常量系数支路上无需对其求导）；
   - `cast(x, to=T)` → 可微浮点之间反向发出 `cast(dout, to=x.dtype)`，跨整数/布尔同样返回 `None`。

注意到没有？**上面所有 `jvp` 和 `vjp` 规则发出的方法，100% 还是 `constant`、`splat`、`add`、`mul`、`cast` 这五个基础方法！** 这意味着微分后的图跟原始前向图没有任何“特殊二等公民节点”，可以无限次继续送进 `jvp`、`vjp`、`prune` 或 `lower_to_ask`。

<a id="jvp-and-vjp"></a>

## 3. `ir.jvp` 与 `ir.vjp` 图级变换（`ir/jvp.py` / `ir/differentiate.py`）

在单算子规则之上，Fuga IR 提供了两个对称的模块级纯变换函数（均不原地修改输入 `Module`）：

- **前向模式 `jvp(module, argnums=...)`**：
  生成新函数，输入参数为 `(*primals, *selected_tangents)`，输出为 `(*primal_outputs, *output_tangents)`。先调用 C++ [`analyze_function`](../architecture/02-原生图分析与C++边界.md#native-analyze) 找出活跃子图，按正向拓扑序同步构造原值与切线（若遇到 `fuga.call` 且该 `ft.fun` 未提供手写 `backward`，直接穿透子函数体做前向微分；遇到活跃路径上的不透明算子则明确报错），最后调用 `prune` 清理未使用的中间节点。
- **反向模式 `vjp(module, argnums=...)`**：
  生成新函数，输入参数为 `(*primals, *output_cotangent_seeds)`，输出严格对应 `argnums` 所选可微输入的梯度列表：
  1. 先对静态可知的 `if`/`for` 做控制流展开化简，使得静态循环里的正向激活值自然成为显式 SSA 值；
  2. 调用 C++ `analyze_function` 拿到 `reverse_ops`（精确排除与所选输入或目标输出无关的死分支与旁路副作用算子）；
  3. 先重放必要的正向计算，再按 `reverse_ops` 严格的逆拓扑序累积每个 SSA 值的余切（多处消费同一个 SSA 值时自动插入 `fuga.add` 累加梯度；遇到带自定义反向的 `fuga.call` 时内联其 `backward` 模块并将正向 `saved` 端口接上；若某个所选可微输入最终未收到任何路径贡献，则补齐精确匹配的零张量）；
  4. 调用 `prune` 剔除反向图中不再需要的正向残留计算（例如 `f(x) = 3 * x` 的反向图经 `prune` 后不再依赖输入 `x` 的具体值），输出最简静态反向图。

正因为 `jvp` 与 `vjp` 在同一套 Fuga IR 上严格闭合，测试集（`tests/test_ir_autodiff.py`）直接验证了 `vjp(jvp(f))` 与 `jvp(vjp(f))` 在 ASK 上编译执行得到的混合二阶导数完全一致。
