## 1. 两类控制流路径

| 机制 | 产生方式 | 编译与求导行为 |
| --- | --- | --- |
| **IR 级结构化区域**（`fuga.if` / `fuga.for` / `fuga.while`） | 通过 `FunctionBuilder` 显式构造 | 保存在 Fuga IR 的嵌套 `Region` 中。当 `if` 条件在编译期可折叠为布尔常量、或 `for` 具有有界静态起止步长时，支持直接做 IR 级 `vjp` 求导并在 [`lower_to_ask`](03-降级到ASK.md#static-simplification) 中展开为单块 ASK 图；动态未决的 `if`/`while` 区域在降级边界报错拒绝。 |
| **Python 运行时图中断**（[Graph Break](../architecture/01-张量模型与追踪机制.md#graph-break)） | 普通 `@ft.jit` 函数中对 0-D 标量张量执行 `if cond:` / `while cond:` | 追踪器在运行时先执行前缀图、读回标量真值，再按实际走过的分支与循环次数调度多个单块静态 Fuga IR 片段，并通过 `GradHistory` 将各片段串联为反向传播链（支持一阶及高阶求导）。 |

## 2. 原语规则表（`ir/primitives.py`）

基础算子在 `PRIMITIVES` 注册表中声明三条规则（`PrimitiveSpec`）：

1. **`abstract_eval(*in_types, **attrs) -> tuple[TensorType, ...]`**：根据输入 `TensorType` 与属性推导输出类型并校验参数。追踪、验证与变换构建器共用同一份推导逻辑。
2. **`jvp(builder, primals, tangents, attrs, results)`**：前向切线传播规则。接收原值 `primals` 与对应切线 `tangents`（无需微分的端口为 `None`），发出切线指令：
   - `constant` → `None`；
   - `splat(x)` → 若 `dx` 存在则生成 `splat(dx, shape)`；
   - `add(a, b)` → `da + db`（单侧为 `None` 时直接返回另一侧）；
   - `mul(a, b)` → `da * b + a * db`；
   - `cast(x, to=T)` → 原值与目标均为可微浮点（`FLOAT_DTYPES`）时生成 `cast(dx, to=T)`；跨越非浮点类型（如 `f32 -> i32 -> f32`）时返回 `None`。
3. **`vjp(builder, primals, cotangents, attrs, results)`**：反向余切传播规则：
   - `add(a, b)` → `(dout, dout)`；
   - `mul(a, b)` → `(dout * b, dout * a)`；
   - `splat(x)` → 0-D 标量恒等 `splat` 直接返回 `dout`（非标量 `splat` 逆向需归约求和，当前仅在无需微分的常量系数支路上使用）；
   - `cast(x, to=T)` → 可微浮点之间生成 `cast(dout, to=x.dtype)`，跨整数或布尔返回 `None`。

上述 `jvp` 与 `vjp` 规则生成的指令仍全部属于 `constant`、`splat`、`add`、`mul`、`cast` 五种基础原语，因此微分后的 `Module` 可以继续作为 `jvp`、`vjp`、`prune` 或 `lower_to_ask` 的输入。

## 3. `ir.jvp` 与 `ir.vjp` 图级变换（`ir/jvp.py` / `ir/differentiate.py`）

两个模块级变换均返回新 `Module`，不原地修改输入：

- **前向模式 `jvp(module, argnums=...)`**：
  生成输入为 `(*primals, *selected_tangents)`、输出为 `(*primal_outputs, *output_tangents)` 的新函数。先调用 C++ [`analyze_function`](../architecture/02-原生图分析与C++边界.md#native-analyze) 获取活跃子图，按正向拓扑序同步构造原值与切线（遇到未自定义 `backward` 的 `fuga.call` 时穿透子函数体做前向微分；遇到活跃路径上的不透明算子报错），最后调用 `prune` 移除未使用的中间节点。
- **反向模式 `vjp(module, argnums=...)`**：
  生成输入为 `(*primals, *output_cotangent_seeds)`、输出对应 `argnums` 所选可微输入梯度的新函数：
  1. 对静态可知的 `if`/`for` 执行控制流化简展开，使循环内的正向激活值成为显式 SSA 值；
  2. 调用 C++ `analyze_function` 获取 `reverse_ops`，排除与所选输入或目标输出无关的分支与旁路副作用算子；
  3. 重放所需的正向计算，按 `reverse_ops` 逆拓扑序累积各 SSA 值的余切（同一 SSA 值被多处消费时插入 `fuga.add` 累加；带自定义反向的 `fuga.call` 内联其 `backward` 模块并接入正向 `saved` 端口；未收到路径贡献的可微输入补齐对应零张量）；
  4. 调用 `prune` 移除反向图中不再需要的正向计算（如 `f(x) = 3 * x` 的反向图剪枝后不再读取 `x`）。

`tests/test_ir_autodiff.py` 对 `vjp(jvp(f))` 与 `jvp(vjp(f))` 在 ASK 上的编译执行结果做了一致性核对。
