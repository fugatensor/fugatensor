## 分支保留两个区域

```python
from fugatensor.ir import Module, TensorType

module = Module()
t = TensorType((3,), "f32")
graph = module.graph("choose", inputs={"x": t}, results=[t])
x = graph.inputs["x"]
predicate = graph.constant(True, dtype="bool")
selected = graph.if_(
    predicate, [x],
    lambda branch, value: branch.mul(value, value),
    lambda branch, value: branch.add(value, value),
)
graph.return_(selected)
```

if 操作拥有两个 region。`[x]` 是显式传入的值，两个回调中的 `value` 是各自 block 的参数。两个分支必须返回相同数量和类型的值。这里条件是编译时已知的常量，提交 ASK 前可以选择平方分支。

IR 也能用 bool 标量参数或零维 bool 张量作为条件。那时条件依赖运行时输入，不能在第一次调用时读一次数据就固定选择某个分支。当前静态专门化只识别可确定的标量条件，执行桥接明确拒绝仍依赖张量数据的图；后续需要由 Fuga 运行时选择分支并调度相应 ASK 可执行片段。

Python `if tensor` 仍会报错。显式 region builder 与 Python 语法捕获是两个功能；本次没有加入 Python AST 或字节码改写器。

## 循环显式携带状态

```python
from fugatensor.ir import Module, TensorType

module = Module()
t = TensorType((3,), "f32")
graph = module.graph("repeat", inputs={"x": t}, results=[t])
result = graph.for_(
    0, 3, 1, [graph.inputs["x"]],
    lambda body, index, carried: body.add(carried, carried),
)
graph.return_(result)
```

for 的范围与 Python `range(lower, upper, step)` 一致。`index` 是 i64 标量 block 参数，`carried` 是本轮状态；body 返回值成为下一轮状态。每轮状态的数量和类型必须保持一致。上例在三轮后得到 `8*x`。

`specialize(module, max_unroll=10000)` 选择常量 if，并展开有界静态 for，生成新的直线图。它设置展开上限，避免大范围循环意外生成巨大图。循环次数与条件只能来自静态已知值，不能从实际 Tensor 读取数据。

while 也有显式条件 region 和 body region，用于保存高层结构。当前专门化不处理 while，因此不能通过当前 ASK 执行桥。保留这个节点不等于已经实现动态循环执行，也不等于有了循环反向传播所需的 tape。

## 基础 VJP 怎样生成反向图

```python
from fugatensor.ir import Module, TensorType
from fugatensor.ir.differentiate import vjp
from fugatensor.lowering import lower_to_ask

module = Module()
t = TensorType((3,), "f32")
graph = module.graph("square", inputs={"x": t}, results=[t])
graph.return_(graph.mul(graph.inputs["x"], graph.inputs["x"]))

backward = vjp(module, argnums=(0,))
ask_backward = lower_to_ask(backward)
```

backward 的参数依次是原图输入和每个输出的 cotangent seed，结果是 `argnums` 指定输入的 cotangent。对平方图，输入 `x` 与 `seed`，输出 `2*x*seed`。显式种子可以处理张量输出和多输出，不假设函数一定返回标量 loss。

VJP 先处理可静态确定的 region，然后逆序遍历操作。add 把传入 cotangent 分别交给两个输入；mul 分别乘以另一侧的正向值。一个输入有多条使用路径时，贡献必须相加，不能后来的结果覆盖前面的结果。返回的是普通 Fuga 运算，因此反向图仍由 ASK 编译并执行。

当前规则支持浮点 add、mul、float-to-float cast 和直接返回已有值。浮点 cast 的反向规则把 cotangent 转回输入精度，沿用常见的混合精度梯度约定；它不是量化舍入函数的严格数学导数。bool/int 输入不能被显式选作求导参数，输出也须为浮点类型。

标量常量及其 splat 可以出现在图中。若要对被 splat 的标量输入求导，需要把张量 cotangent 归约成标量；当前没有归约算子，这种情况明确报错。依赖外部调用的梯度也会报错，要求先提供该外部算子的 VJP 规则，不能把未知导数当成零。这里没有注册任意 Triton kernel 梯度的接口。

这是一项显式 IR 变换。当前没有 `Tensor.backward()`、隐式累积到 `.grad`、自动保存激活的 tape 或完整高阶微分接口。后续增加这些 API 时，可以在 Fuga IR 上完成；ASK 只需继续编译最后得到的计算图。

下一步的接口方案见 [JIT、grad 与 fun 类提案](04-JIT与自定义梯度提案.md)：由 fun 类定义正向和反向，grad 选择规则，jit 编译实际需要的函数体。该提案没有改变本页的已实现范围，当前仍不能注册自定义梯度或嵌套调用 JIT。
