## 1. 两类控制流路径

| 机制 | 产生方式 | 编译与求导行为 |
| --- | --- | --- |
| **IR 级结构化区域**（`fuga.if` / `fuga.for` / `fuga.while`） | 用 `Function` / `BlockBuilder` 构造 | 保存为嵌套 `Region`。常量条件的 `if` 和静态整数区间的 `for` 可化简后求导，再经 [`lower_to_ask`](降级到ASK.md#static-simplification) 转成单块 ASK 图。数据依赖的 IR `if` 和所有 IR `while` 当前无法降级。 |
| **Python 标量条件边界**（[按需执行](../architecture/张量模型与追踪机制.md#graph-break)） | 普通 Python 中对 0-D Tensor 执行 `if cond:` / `while cond:` | 读取条件真值时编译并执行其依赖图，Python 按实际分支与循环次数继续构建 Tensor 表达式；各阶段的梯度历史保持连接。自定义 `ft.fun` 的隔离追踪不支持这类数据依赖控制流。 |

<a id="primitive-registry"></a>

## 2. 原语规则表（`ir/primitives.py`）

基础算子在 `PRIMITIVE_RULES` 注册表中声明三条规则（`PrimitiveRule`）：

1. **`abstract_eval(input_types, attrs)`**：根据输入类型与语义属性推导输出类型 tuple 并校验参数，支持标量与张量。追踪、验证与变换构建器共用同一份推导逻辑。
2. **`jvp(builder, operation, primals, tangents)`**：前向切线传播规则。接收原值 `primals` 和切线 `tangents`（非微分端口为 `None`），生成切线指令：
   - `constant` → `None`；
   - `splat(x)` → 若 `dx` 存在则生成 `splat(dx, shape)`；
   - `add(a, b)` → `da + db`（单侧为 `None` 时直接返回另一侧）；
   - `mul(a, b)` → `da * b + a * db`；
   - `cast(x, to=T)` → 原值与目标均为可微浮点（`FLOAT_DTYPES`）时生成 `cast(dx, to=T)`；求导路径跨越非浮点类型时报错。
   - `reshape(x, shape)` → 将 `dx` 改为输出形状。
3. **`vjp(builder, operation, primals, cotangent, active)`**：反向余切传播规则，`active` 指示需要梯度的输入：
   - `add(a, b)` → `(dout, dout)`；
   - `mul(a, b)` → `(dout * b, dout * a)`；
   - `splat(x)` → 常量系数支路跳过求导；对活跃标量输入求导会报错，所需的归约规则尚未实现；
   - `cast(x, to=T)` → 可微浮点之间生成 `cast(dout, to=x.dtype)`，求导路径跨整数或布尔时报错；
   - `reshape(x, shape)` → 将 `dout` 恢复为 `x.shape`。

这些规则生成的指令仍属于六种基础原语，导数 `Module` 可以继续交给 `jvp`、`vjp`、`prune` 或 `lower_to_ask`。

<a id="jvp-and-vjp"></a>

## 3. `ir.jvp` 与 `ir.vjp` 图级变换（`ir/jvp.py` / `ir/differentiate.py`）

两个变换都返回新的 `Module`：

- **前向模式 `jvp(module, argnums=...)`**：
  新函数输入为 `(*primals, *selected_tangents)`，输出为 `(*primal_outputs, *output_tangents)`。先化简静态区域，再用 C++ [`analyze_function`](../architecture/原生图分析与C++边界.md#native-analyze) 找到活跃子图，按拓扑序生成原值和切线，最后调用 `prune`。当前活跃路径中的 `fuga.call` 和外部算子缺少 JVP 规则，会报错。
- **反向模式 `vjp(module, argnums=...)`**：
  生成输入为 `(*primals, *output_cotangent_seeds)`、输出对应 `argnums` 所选可微输入梯度的新函数：
  1. 选择静态 `if` 分支、展开静态 `for`，将各轮中间值转为 SSA 值。
  2. 调用 C++ `analyze_function` 获取反向遍历顺序；源图须无副作用，任何 `effects` 非空的节点都会导致报错。
  3. 重放前向计算，按逆拓扑序累积余切。共享值的梯度用 `fuga.add` 累加；自定义 `fuga.call` 接入 `backward` 子图和正向 `saved` 端口；没有梯度贡献的可微输入补零。
  4. 调用 `prune` 删除反向图中的死节点。例如 `f(x) = 3 * x` 的导数图只保留常数和梯度种子。

`tests/test_ir_autodiff.py` 对 `vjp(jvp(f))` 与 `jvp(vjp(f))` 在 ASK 上的编译执行结果做了一致性核对。
