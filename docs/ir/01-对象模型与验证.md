## 1. 类型与 SSA 值（`ir/types.py` / `ir/core.py`）

- **`TensorType(shape, dtype)`**：
  - `dtype` 支持 `("bool", "i32", "i64", "f32", "f16", "bf16")` 六种类型（`fp16` 在构造入口规范化为 `"f16"`），可微浮点集合定义为 `FLOAT_DTYPES = frozenset(("f16", "bf16", "f32"))`。
  - `shape` 为非负整数 tuple：0-D 标量为 `()`（文本打印为 `f32`、`i32`），多维或空张量为 `(2, 3)`、`(0, 4)`（打印为 `tensor<2x3xf32>`、`tensor<0x4xf32>`）。
  - 所有维度为静态整数，不包含设备属性。
- **SSA `Value`**：
  - 每个 `Value` 具有唯一 `value_id`（如入口参数 `fuga_main.arg0`、算子结果 `op12.res0`）、打印短名（`%arg0`、`%v3_0`）、`TensorType`、所属 `Block`（`owner`）及定义算子 `producer`（块参数的 `producer` 为 `None`）。
  - 每个 `Value` 只定义一次，图变换与跨层映射均以 `value_id` 作为标识。

<a id="ops-and-regions"></a>

## 2. 操作、基本块、区域与模块层次

```text
Module (functions, metadata={"functions": {...}, "external_implementations": {...}})
 └── Function (name, region, inputs, input_types, output_types)
      └── Region (blocks=[entry_block])
           └── Block (arguments, operations)
                └── Operation (op, operands, results, attrs, regions, origin_id)
```

当前支持的 `Operation.op` 列表：

| 类别 | 操作名 | 语义与属性 / 区域 |
| --- | --- | --- |
| **常量与广播** | `constant` | 无操作数，产生一个 0-D 标量值，`attrs["value"]` 保存 Python 标量（浮点文本打印使用十六进制 `float.hex()` 保持二进制精确值）。 |
| | `splat` | 将 0-D 标量操作数复制填充到 `attrs["shape"]` 指定的张量形状。 |
| **基础逐元素** | `add`、`mul` | 接收两个同 shape、同非 `bool` dtype 的张量，产生同类型结果。 |
| | `cast` | 将单个输入张量显式转换为 `attrs["to"]` 目标 `dtype`（shape 不变）。 |
| **函数与外部算子** | `call` | 调用 `Module.metadata["functions"][callee]` 中的子函数（如 [`ft.fun`](../architecture/03-自动微分与自定义算子.md#custom-fun)），结果包含公开输出及 `saved_count` 个供反向使用的中间值。 |
| | `external` | 调用第三方编译器算子，`attrs["spec"]` 保存 `ExternalSpec`（编译器 ID、源码原文、端口绑定、常量、grid 与副作用列表）。 |
| **结构化控制流** | `if` | 接收 0-D `bool` 条件，含 `then` 与 `else` 两个单块 `Region`，两分支 `yield` 的结果类型列表必须一致。 |
| | `for` | 静态区间计数循环（`attrs` 含 `start`、`stop`、`step`），循环体 `Region` 块参数依次为 `i64` 归纳变量与 `init_args` 携带状态。 |
| | `while` | 含 `cond` 与 `body` 两个 `Region`：`cond` 以 `condition(flag, *carried)` 终结，`body` 以 `yield(*next_carried)` 终结。 |
| **终结符** | `return`、`yield`、`condition` | 分别作为顶层 `Function`、分支/循环体 `Region` 与 `while` 条件 `Region` 的末尾终结指令。 |

`Operation.origin_id` 在克隆、循环展开或微分生成新节点时继承源节点 ID，最终记录到 [`fuga-to-ask.json`](03-降级到ASK.md#external-and-sourcemap)。

<a id="module-verifier"></a>

## 3. 结构化校验器（`ir/verify.py`）

`verify_module(module)` 在框架层检查 IR 合法性，违规时抛出 `VerificationError`：

1. **支配与作用域**：任意操作数必须是当前（或外层祖先）`Block` 的入口参数，或是同一块中排在前面的指令、或外层祖先块中排在父指令之前的指令所产生的结果，不允许跨分支引用或先使用后定义。
2. **块结构与终结符**：每个 `Region` 包含单个非空 `Block`，终结符（`return` / `yield` / `condition`）只能且必须位于块末尾，操作数类型与 `Function.output_types` 或父控制流指令的返回类型逐一匹配。
3. **算子类型约束**：`add`/`mul` 拒绝 `bool` 或不一致的 shape/dtype、`splat` 要求输入为 0-D 标量、`if`/`condition` 要求条件为 0-D `bool`、`for` 要求 `step != 0` 且块参数与初始状态对齐、`call` 校验被调子函数签名一致。
