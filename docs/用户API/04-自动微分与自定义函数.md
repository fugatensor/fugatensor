# 04. 自动微分与自定义函数

创建浮点张量时设置 `requires_grad=True`，对结果调用 `backward()`，再从叶子张量的 `.grad` 读取梯度。只有 `f16`、`bf16`、`f32` 支持求导；整数和布尔张量不能设置 `requires_grad=True`。

<a id="gradient-state"></a>
## 梯度状态与清理

| 接口 | 返回值与用途 |
| --- | --- |
| `x.requires_grad` | 只读 `bool`，表示是否记录该张量的梯度依赖。 |
| `x.is_leaf` | 只读 `bool`，表示张量是否没有上游梯度历史；直接创建的张量和 `detach()` 的结果都是叶子。 |
| `x.grad` | 只读 `Tensor` 或 `None`；反向结果累加到需要梯度的叶子上，中间结果不会自动保留 `.grad`。 |
| `x.zero_grad(*, set_to_none=True)` | 返回 `None`。默认把 `.grad` 置为 `None`；传 `False` 时，将已有梯度替换为同形状、同类型的零张量。原本没有梯度时仍为 `None`。 |

`zero_grad()` 只清理累计梯度，不恢复已释放的反向图。

<a id="backward"></a>
## 反向传播

`x.backward(gradient=None, *, retain_graph=None, create_graph=False)` 返回 `None`，执行反向计算并更新叶子的 `.grad`。

| 参数 | 含义 |
| --- | --- |
| `gradient` | 输出的梯度种子。形状为 `()` 的标量可以省略，默认种子为 1；非标量必须显式传入 Tensor，且 Engine、形状、dtype 与输出一致。 |
| `retain_graph` | 是否保留反向历史。`None` 跟随 `create_graph`；默认反向完成后释放历史。若要对同一表达式再次反向，第一次就应传 `True`。 |
| `create_graph` | 是否让本次算出的梯度继续可微，用于高阶导数；默认 `False`。 |

非标量输出不会隐式求和。每次反向都会累加已有梯度，需要独立的一轮梯度时先调用 `zero_grad()`。

```python
import fugatensor as ft

with ft.Engine("cpu"):
    x = ft.tensor([2.0, 3.0], requires_grad=True)
    y = ft.square(x)
    seed = ft.ones_like(y)
    y.backward(seed, retain_graph=True)
    assert x.grad.tolist() == [4.0, 6.0]
    y.backward(seed)
    assert x.grad.tolist() == [8.0, 12.0]
    x.zero_grad()
    assert x.grad is None
```

高阶求导时，先保存一阶梯度，再清空叶子的累计值，避免把两阶结果相加：

```python
import fugatensor as ft

with ft.Engine("cpu"):
    x = ft.tensor(2.0, requires_grad=True)
    y = x * x * x
    y.backward(create_graph=True)
    first = x.grad
    assert first.tolist() == 12.0
    x.zero_grad()
    first.backward()
    assert x.grad.tolist() == 12.0
```

高阶导数要求梯度计算仍由可微原语组成；包含不透明外部 kernel 的路径不会自动得到高阶规则。缺失反向规则会在更新叶子梯度前报错。支持边界见[高阶导数](../architecture/03-自动微分与自定义算子.md#higher-order)。

<a id="stop-gradient"></a>
## 停止记录梯度

`x.detach()` 返回一个没有梯度历史、`requires_grad=False` 的 Tensor。它不复制数据；若原张量尚未计算，仍保留数值依赖，调用本身不会立即执行。

`ft.no_grad()` 可以作为上下文管理器或 `@ft.no_grad()` 装饰器，在构建表达式时停止记录梯度。退出上下文后再读取结果，也不会补建历史。

```python
import fugatensor as ft

with ft.Engine("cpu"):
    x = ft.tensor(3.0, requires_grad=True)
    detached = x.detach()
    with ft.no_grad():
        y = ft.square(x)
    assert not detached.requires_grad and detached.is_leaf
    assert not y.requires_grad
    assert y.tolist() == 9.0
```

<a id="custom-functions"></a>
## 自定义函数 `ft.fun`

继承 `ft.fun`，定义普通实例方法 `forward(self, ctx, ...)`，通过实例调用执行。至少传入一个 Tensor；前向返回一个 Tensor 或非空 Tensor tuple。只做前向时可以省略 `backward`；该调用参与求导时，必须显式提供 `backward(self, ctx, dy)`。

| 接口 | 契约 |
| --- | --- |
| `ctx.save_for_backward(*values)` | 仅在 `forward` 中保存当前前向的张量，返回 `None`；多次调用以最后一次为准。 |
| `ctx.saved_tensors` | 仅在 `backward` 中读取，返回保存张量的 tuple。 |
| `backward(self, ctx, dy)` | `dy` 与前向返回结构一致：单 Tensor 对应单 Tensor，tuple 对应 tuple。返回所有浮点 Tensor 输入的梯度 tuple，按输入顺序排列，形状与 dtype 必须逐项匹配。整数、布尔和静态参数不占梯度位置。 |
| `op.clear_cache()` | 返回 `None`，使已记录的调用失效；用于修改闭包或全局变量等未自动跟踪的 Python 捕获后重新构图。 |

反向即使只有一个梯度，也必须返回 `(dx,)`；不能用 `None` 占位。

```python
import fugatensor as ft

class Square(ft.fun):
    def forward(self, ctx, x):
        ctx.save_for_backward(x)
        return ft.square(x)

    def backward(self, ctx, dy):
        (x,) = ctx.saved_tensors
        return (2.0 * x * dy,)

with ft.Engine("cpu"):
    x = ft.tensor(3.0, requires_grad=True)
    Square()(x).backward()
    assert x.grad.tolist() == 6.0
```

`forward` 和 `backward` 都会隔离追踪，不支持基于 Tensor 数值的 Python `if` / `while`，也不支持递归或追踪期间修改函数状态。实例或类的配置属性只接受不可变 `bool` / `int` / `float` / `str` / `None` 及其嵌套 tuple，Tensor 状态应通过参数传入。修改已记录调用的方法或配置后，应重新调用构图；旧调用会被拒绝。定义检查的原因见[自定义函数边界](../architecture/03-自动微分与自定义算子.md#custom-fun)。
