## 1. 运行时 `GradHistory` 与反向调度（`autograd.py`）

梯度历史在表达式创建时记录。`ft.no_grad()` 内创建的表达式跳过记录，之后读取结果也保持这一状态。

1. **挂载历史节点**：输入含需梯度的浮点张量时，`_Node` 保存 Fuga IR、输入 Tensor、输出身份与类型、求导输入端口。输出通过节点及输出索引连接上游历史。
2. **检查梯度种子**：0-D 输出省略种子时使用同设备、同类型的标量 `1.0`；非标量必须提供同形状、同类型、同 Engine 的种子。错误种子与不可求导路径在执行前拒绝。
3. **逆拓扑回传与叶子累加**：用 [`project_outputs`](原生图分析与C++边界.md#transforms-reuse) 选取收到余切的输出，裁剪无关分支，构造各节点的 [`vjp`](../ir/控制流与可组合变换.md#jvp-and-vjp) 计划。预检通过后合并执行反向及累加表达式，成功后更新叶子 `.grad`。
4. **图生命周期**：默认在 `backward()` 后释放历史，再次反向会报错；`retain_graph=True` 可保留历史，`create_graph=True` 默认也会保留。`detach()` 保留数值依赖并断开梯度连接；`zero_grad()` 清空 `.grad`。

实际依赖范围由 C++ 图分析确定。普通 Python 标量条件前后的图通过 Tensor 输入连接，反向沿此次实际计算路径传播。

<a id="custom-fun"></a>

## 2. `ft.fun` 自定义前向与反向（`function.py`）

需要自定义梯度公式或为外部 Triton 算子提供反向实现时，继承 `ft.fun`：

```python
class ScaleAndSquare(ft.fun):
    def forward(self, ctx, x):
        ctx.save_for_backward(x)
        return ft.square(x)

    def backward(self, ctx, dy):
        (x,) = ctx.saved_tensors
        return (2 * x * dy,)
```

- 调用 `op(x)` 时隔离追踪 `forward`，将子模块和定义检查保存到 `CallSpec`，在外层插入 `fuga.call`。构图后修改实例配置或替换方法，会使旧图报错。
- 求导配置放在实例的不可变属性中，运行时 Tensor 通过参数传入。修改闭包或全局变量中的可变内容后，须调用 `op.clear_cache()` 并重新构图；这些捕获内容不在定义检查范围内。
- `ctx.save_for_backward(...)` 将中间张量保存为 `fuga.call` 的额外 `saved` SSA 输出，供 VJP 使用，也参与剪枝和缓存分析。
- VJP 追踪 `backward(ctx, dy)`，校验梯度 tuple 的长度和各输入的 shape/dtype。反向可以调用 [`ft.triton.kernel`](ASK桥接与多后端执行.md#cuda-and-triton)；引擎裁剪未用输入，ASK 将外部 kernel 排入执行计划。

<a id="higher-order"></a>

## 3. 基于 JVP / VJP 闭合的高阶自动微分

已有 JVP/VJP 规则生成的导数图仍由 `constant`、`splat`、`add`、`mul`、`cast`、`reshape` 组成。例如乘法的 VJP 生成两条 `fuga.mul`，共享输入的梯度用 `fuga.add` 累加；浮点转换和 reshape 分别生成反向 cast 和 reshape。各规则的适用范围见[原语规则表](../ir/控制流与可组合变换.md#primitive-registry)。

`y.backward(create_graph=True)` 为 VJP 计算继续记录梯度历史。保存 `first = x.grad`，调用 `x.zero_grad()` 后再执行 `first.backward()`，可继续对该图求导。

<a id="preflight-validation"></a>

## 4. 反向预检（Preflight Validation）

`autograd.py` 在编译反向节点和更新叶子 `.grad` 前检查整张反向图：

1. 根据 C++ [`analyze_function`](原生图分析与C++边界.md#native-analyze) 的 `reverse_operations` 定位当前求导路径上的算子；
2. 构建各节点的 `vjp` 模块。活跃的裸 `fuga.external` 缺少反向规则时抛出 `TypeError` / `ValueError`；`create_graph=True` 还会检查正向和反向图中的不透明外部算子，这类路径当前不支持高阶求导；
3. 全部节点的反向 IR 通过构建与校验后，才开始编译执行并更新叶子 `.grad`。
